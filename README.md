# 📚 SemExam (College Resource Hub)

**SemExam** is a full-stack academic resource platform specifically curated for the students of **National Institute of Technology Karnataka (NITK)**. It simplifies exam preparation by eliminating scattered Google Drive links and WhatsApp archives, offering a fast, centralized repository for Previous Year Questions (PYQs), course notes, and textbooks.

---

### ✨ Features
* 🔍 **Instant Search & Multi-Filter:** Quickly filter resources by department, subject code, semester, year, and exam type (Mid-Sem, End-Sem, Quiz).
* 📑 **Categorized Resources:** Dedicated views for **PYQs**, **Class Notes**, and **Textbooks**.
* ⚡ **Live Ingestion Pipeline:** Automated metadata extraction and ingestion script powered by the Google Drive API.
* 🛡️ **Admin Controls:** Streamlined moderation tools to manage and approve incoming student resources.

---

### 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS, Lucide Icons, Vite
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas (Mongoose ODM)
* **Storage & APIs:** Google Drive API, Cloudinary
